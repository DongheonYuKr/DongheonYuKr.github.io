개인정보처리방침

시행일: 2026년 11월 25일

이 방침이 다루는 것

heonlog가 운영하는 유튜브 채널(재구매 목록, 우주카메라, 물건개정판)에 운영자 본인이 만든 영상을 올리기 위한 내부 업로드 도구 「heon youtube upload」에 적용됩니다.

받는 정보와 쓰는 곳

  • 운영자 본인의 구글 계정으로 받은 유튜브 업로드 허락(OAuth 토큰)만 씁니다.
  • 이 허락은 운영자 본인의 채널에 영상과 제목·설명을 올리고, 어느 채널인지 확인하는 데에만 씁니다.
  • 다른 사람의 계정이나 개인정보는 받지 않으며, 광고·판매·제3자 제공에 쓰지 않습니다.

보관과 삭제

  • 허락 정보는 운영자의 컴퓨터 안 암호 보관함에만 저장하고, 다른 서버로 보내지 않습니다.
  • 운영자는 언제든 구글 계정의 보안 설정(타사 앱 액세스)에서 이 도구의 허락을 끊을 수 있고, 끊으면 저장된 허락은 더 이상 쓰이지 않습니다.

구글 정책

이 도구가 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 따릅니다. 유튜브 API를 쓰므로 YouTube 서비스 약관과 Google 개인정보처리방침도 함께 적용됩니다.

English summary

“heon youtube upload” is an internal tool used only by the heonlog operator to upload the operator’s own videos to the operator’s own YouTube channels. It uses only the operator’s OAuth token, stored locally in the operator’s computer keychain, and does not collect, sell or share anyone else’s data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
