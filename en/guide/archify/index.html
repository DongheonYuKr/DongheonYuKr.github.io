How to use archify: turn a hard-to-explain workflow into one picture

If you're still explaining your workflow in long paragraphs, look at this tool first. archify is a free GitHub tool: describe an idea, a plan or a work process in plain words, and it turns it into one clickable diagram (a single web page). I'm not a developer. I had AI install it on my computer, used it, and wrote down exactly what happened.

GitHub: tt-a1i/archify · License: Apache-2.0 (commercial use allowed) · about 92k stars (as of Oct 31, 2026) · Installed Oct 30, 2026

What it does

Say something like “draw this process as a diagram,” and it builds a web page that shows the steps, branches and order as a picture. Both light and dark themes work, and you can export it as an image file. It isn't an app that runs on its own. It's a “skill” pack that an AI assistant such as Claude Code or Codex reads and uses.

Install difficulty: ⭐⭐⭐ (needs the terminal)

  • The downloaded folder has to go into your AI assistant's skills folder (a hidden folder), so you use the terminal (the black command window).
  • You need an AI assistant like Claude Code and Node 18 or later first.
  • The easy part: no sign-up, no payment, no API key.
  • I had the AI check what was inside before installing, and only then let it install. Doing it alone in the terminal could be harder.

Where I got stuck

  • A feature that checks GitHub once a day for a new version was turned on. It was the only outgoing connection, so I turned it off.
  • It suggests turning on a “one-page explainer” mode. That feature writes a line into the AI settings file for your whole computer, so I left it off.
  • The first diagram had to be scrolled sideways on a phone. On a computer screen nothing overlapped or got cut off.

What I made with it

  • I turned my 8-step process for making social media posts (from collecting material to a human check at the end) into one diagram.
  • Since then I keep using it for things that take too long to explain in words, like business plans and weekly plans.

The catch

It's not a program that runs by itself. It only works when you call it from inside an AI assistant (Claude Code, Codex and so on). If you don't use an AI assistant yet, you need to set that up first before you can use this tool.

FAQ

Is it free? Can I use it commercially?

Yes. The license is Apache-2.0, so commercial use is allowed. I didn't need a sign-up, payment or API key.

Can I use it without Claude Code?

No. It isn't a program that runs on its own. It's a “skill” pack that only works when you call it from inside Claude Code or Codex.

Does it connect to the internet?

The only outgoing connection I found was a daily check on GitHub for a new version, and I turned it off.
