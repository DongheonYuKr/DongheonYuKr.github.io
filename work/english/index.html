한국 상품·영상을 영어로

한국어로 만든 영상과 상품 설명을 해외 사람이 읽는 영어로 옮깁니다. AI한테 시켜 초벌을 만들고, 마지막 문장 확인은 제가 직접 합니다. 아래 견본은 제 한국어 가이드 한 편을 직접 영어로 옮긴 것입니다.

두 가지 일

① 영어 자막 + 영어 제목·설명

해외 시청자를 원하는 한국 뷰티·요리·여행 소형 유튜버를 위한 일입니다. 영상 자막 파일(.srt)과 영어 제목·설명란 글을 드립니다.

15,000원 · 30,000원 · 55,000원 크몽 기준

② 해외 K-뷰티 셀러용 영어 상품 설명

아마존·쇼피파이 등에서 K-뷰티를 파는 해외 소형 셀러를 위한 일입니다. 한국어 상품 설명을 미국 손님이 읽는 말투로 바꾸고, 전성분은 제품 표기 그대로 영어 이름으로 정리합니다.

25,000원 · 59,000원 · 109,000원 크몽 기준

상품 1개 기준입니다. 주문과 결제는 크몽에서 합니다(승인 대기 중).

SAMPLE

GitHub Teardown #01 · HEONLOG

archify: turn a hard-to-explain workflow into one picture

Still explaining your workflow in long paragraphs? Start here. archify is a free GitHub tool that turns an idea, a plan or a work process into a single clickable diagram (a one-page web page) — you just describe it in plain words. I'm not a developer; I had an AI assistant install it for me and wrote down exactly what happened.

GitHub: tt-a1i/archify · License: Apache-2.0 (commercial use allowed) · about 92k stars (as of Oct 31, 2026) · Installed Oct 30, 2026

What it does

Say "draw this process as a diagram," and it builds a web page that lays out the steps, branches and order. It supports light and dark themes and can export to an image file. It isn't a standalone app: it's a "skill" pack that AI assistants such as Claude Code or Codex read and use.

Install difficulty: ⭐⭐⭐ (needs the terminal)

  • You have to place the downloaded folder in your AI assistant's (hidden) skills folder, which means using the terminal.
  • You'll need an AI assistant like Claude Code and Node 18 or later first.
  • The easy part: no sign-up, no payment, no API key.

Where I got stuck

  • It checks GitHub once a day for a new version. That was its only outgoing connection, so I turned it off.
  • It suggests turning on a "one-page explainer" mode, which writes a line into your computer-wide AI settings file. I left it off.

The catch

It won't run on its own. It only works when called from inside an AI assistant. If you don't use one yet, set that up first.

견본은 가이드의 앞부분(1쪽 분량)입니다. 맡기실 때는 영상·상품 설명 전체를 옮깁니다.

진행 순서

  1. 인포크 「비즈니스 제안」으로 문의합니다. 영상 링크나 상품 설명 원문이 어디 있는지 적어 주세요.
  2. 본인이 권리를 가진 영상·상품 설명인지 확인합니다.
  3. 짧은 한 부분을 먼저 옮겨 말투를 맞춥니다.
  4. 전체를 옮기고, 마지막 문장 확인은 제가 직접 합니다.
  5. 받으신 뒤 한 번 고쳐 드립니다. 올리는 것은 직접 하시면 됩니다.

하지 않는 것

  • 조회수·판매량·검색 순위 보장
  • 목소리를 복제한 영어 더빙
  • 화장품을 「치료한다·낫게 한다」처럼 쓰는 효능 표현 (원문에 있어도 옮기지 않고 말씀드립니다)
  • 필러·스킨부스터 같은 의료기기, 의약품, 건강기능식품 설명
  • 판매 국가의 등록·표시 의무 판단 (미국 MoCRA 등 — 셀러 본인 확인 사항입니다)

문의
