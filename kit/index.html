깃허브 도구, 깔기 전에 이 4가지만 확인하세요

깃허브 무료 도구 다섯 개를 직접 깔아 보면서 실제로 걸렸던 지점을 질문 4개로 바꿨습니다. 어느 도구든 똑같이 씁니다. 2쪽 PDF, 무료입니다.

  1. 라이선스 — 상업적으로 써도 되는지, 안에서 고르는 모델·목소리의 조건은 따로인지
  2. 돈 나가는 길 — API 키·로그인 칸, 무료 한도와 자동 결제
  3. 모든 대화에 붙는 장치 — 컴퓨터 전체 설정에 써 넣는 기능, 깔리는 위치
  4. 밖으로 나가는 정보 — 저절로 밖에 연결하는 기능, SNS 로그인 연결

2쪽에는 깔기 전에 클로드 코드에 붙여 넣는 확인 문장이 있습니다. 「깔지는 말고」가 들어 있어서 그 문장만으로는 아무것도 깔리지 않습니다.
